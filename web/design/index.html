La Carte, le design system du magazine

Le magazine se lit comme une carte aéronautique : du papier de carte pour lire, le bleu des cartes pour les données, le magenta de l'OACI pour ce dont parle l'article, la nuit et son quadrillage pour les ouvertures. Une seule palette pour tout le site ; chaque signe veut dire une seule chose.

Les principes

  1. Une couleur, un sens. Le magenta désigne le constat, le sujet de l'article ou la série dont il parle. Jamais une décoration.
  2. Un titre est une phrase. Pas de mot isolé dans une autre couleur ; le titre d'une figure dit ce qu'on apprend, son sous-titre la mesure et l'unité.
  3. Le triangle est une étape. Comme un point de report sur une route aérienne : numéro de chapitre, étape de l'essentiel, plan de vol d'un article, progression de lecture.
  4. La nuit ouvre. Ouvertures, parties et pied de page sont sur la nuit quadrillée ; on lit sur le papier.
  5. Le texte respire. Une colonne de lecture d'environ 65 signes, deux chiffres au plus par phrase.

La typographie

Deux familles bien distinctes. Archivo, un peu étroit, est le lettrage de la carte : titres, chiffres, légendes. Source Serif est la voix du texte. Échelle de 1,25 à partir de 16 px.

Titre d'ouverture

--t-display Archivo, chasse 78 %, graisse 720

Titre de chapitre, une phrase

--t-3xl Archivo, même chasse et graisse

Titre de figure : un constat

--t-xl Archivo, graisse 700

Le texte se lit en Source Serif, à 18 px environ, sur une colonne de quarante cadratins. Un chiffre y est en gras, 34 %, jamais plus de deux par phrase.

--t-read Source Serif 4, interlignage 1,6

Sous-titre de figure : la mesure et l'unité, en Archivo 0,9 rem.

Les deux formats

En 5 minutes

Une question, sa réponse tout de suite, un plan de vol de quatre étapes ; chaque étape est une question simple, une figure, deux paragraphes. Ouverture sur le papier. Code : src/court/.

L'enquête

Une ouverture sur la nuit avec sa figure, l'essentiel en étapes, des parties en bandeaux de nuit, des chapitres numérotés, des outils. Code : src/site/story.js.
