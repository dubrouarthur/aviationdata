Les données

Toutes les sources des enquêtes : qui les produit, ce qu'elles couvrent, à quelles conditions on peut les réutiliser, les figures qui les citent, les fichiers que nous en tirons et le code qui les lit. Chaque fichier se télécharge ; chaque traitement se relit.

Les jeux de données

Les références

Les valeurs qui convertissent une donnée en une autre, les textes qui la définissent, et les modèles avec lesquels la troisième enquête lit les accidents.

Les repères datés

Les faits extérieurs aux données que les enquêtes citent, chacun avec sa date et sa source. Ils situent les courbes dans le temps ; aucune enquête ne les présente comme la cause de ce que montrent les chiffres.

Nos fichiers

Les fichiers que lisent les pages, tels qu'ils sont publiés. Ils dérivent des données de leurs producteurs, dont les conditions s'appliquent ; pour les réutiliser, citez le producteur et aviationdata.

Vérifier

Les fichiers bruts sont téléchargés par des scripts, jamais à la main, puis transformés par le code nommé dans chaque fiche. Avant chaque publication, d'autres scripts rechargent les pages, relisent chaque chiffre écrit dans le texte, le recalculent depuis les fichiers publiés et échouent s'ils ne tombent pas juste ; des tests refont une partie des calculs depuis les fichiers des producteurs.

Le code est public, sur GitHub. Une erreur, une source manquante ? Signalez-la : les corrections sont datées dans le journal des corrections.
