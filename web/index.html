Les outils

Chaque enquête contient des outils à manipuler soi-même, sur les mêmes données que le texte. Ils s'ouvrent directement à leur place dans l'enquête.

Comment ces enquêtes sont faites

Trois règles, détaillées dans la charte du magazine, avec la politique de corrections.

Des données publiques, et seulement elles

Chaque chiffre vient d'un jeu de données ouvert, cité à côté : la DGAC pour le trafic français, Copernicus et la NOAA pour les vents, Météo-France pour les ballons-sondes, la NASA pour les images satellites, OpenSky pour les vols, le NTSB pour les accidents.

Des chiffres recalculés, pas recopiés

Les textes sont écrits à partir des données traitées : un script recalcule chaque nombre cité et le compare à la page avant toute publication. Quand une donnée manque, le trou reste visible.

Les limites dites

Une corrélation n'est pas une cause. Les faits extérieurs aux données sont datés et sourcés, et chaque enquête finit par sa méthode, ses sources et ce qu'elle ne permet pas de dire.
